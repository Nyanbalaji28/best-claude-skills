## How to install

**The easy way (any terminal, no plugins needed):** open a skill's page on AugmentClaude below and paste its install command into Claude Code or your terminal.

**The power-user way:** add this repo as a marketplace inside Claude Code:

```
/plugin marketplace add Nyanbalaji28/best-claude-skills
```

then `/plugin` to browse and install. (If `/plugin` isn't available in your setup, use the easy way — it always works.)

## What are Claude skills?

Claude skills are small instruction files that Claude Code loads on startup. Each one teaches Claude a single domain — writing tests, reviewing designs, editing spreadsheets — and Claude auto-activates the right one when your request matches. Installing skills is the fastest way to augment Claude with new abilities.
